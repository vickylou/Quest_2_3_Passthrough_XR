Suggestion math (suggestProportional)
Input: the current allocations map and the just-edited person's id +
value. Output: suggested values for the OTHER sisters such that the total
stays at 100 %, distributed proportionally to their existing values.

suggestProportional(allocations, editedId, editedVal):
  others = sum(allocations[p] for p in PERSON_IDS if p != editedId)
  target = 100 - editedVal
  if others <= 0:
    # nothing to scale; even-split fallback for the others
    each = target / 3
    return { p: each for p != editedId }
  factor = target / others
  return { p: allocations[p] * factor for p != editedId }
The suggestion is ONLY rendered, never auto-applied. Click to accept.
